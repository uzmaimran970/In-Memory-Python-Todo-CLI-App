Welcome to Local Kubernetes AI Operations

Status: Application is running in local Kubernetes cluster

This is a sample frontend application demonstrating the Local K8s AI Ops setup.

Features:

  • Deploy applications using natural language commands
  • Manage Kubernetes resources with AI assistance
  • Fallback to standard Docker operations when needed
  • Zero-cost, learning-oriented environment

Quick Commands:

# Deploy with AI
kubectl ai "deploy myapp with 2 replicas"

# Expose service
kubectl ai "expose deployment myapp on port 80"

# Scale application
kubectl ai "scale deployment myapp to 3 replicas"
